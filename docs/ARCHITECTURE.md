# XAAA Architecture

## Function

XAAA is the experiential layer of the autopoietic ontology. It transforms knowledge into wisdom by exposing the user to mediated scenarios, consequences and counterfactuals.

## Six layers

| Layer | Name | Role |
|---|---|---|
| L1 | Experience Input | scenario, context, user decision |
| L2 | Consequence Simulation | immediate/delayed outcomes |
| L3 | Counterfactual Engine | safer path, missed option |
| L4 | Socratic Reflection | guided questions, maieutic review |
| L5 | Wisdom Trace | operational rule, transfer domains |
| L6 | Experience Memory | pruning, retrieval, preparation for TAAA/NOAH |

## Runtime

```text
Scenario -> Decision -> Consequence -> Counterfactual
         -> Socratic Reflection -> Wisdom Trace -> Experience Memory
```
